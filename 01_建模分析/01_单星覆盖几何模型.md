# 问题一（1）：单颗卫星覆盖几何模型

## 1. 建模目标

在球形地球假设下，推导轨道高度为 \(h\)、天线半锥角为 \(\alpha\) 时，单颗卫星覆盖区的：

1. 覆盖边界地心角 \(\psi\)；
2. 地面覆盖半径 \(s\)；
3. 覆盖面积 \(A\)；
4. 任意地面点的覆盖判据。

本节只建立几何内核，不讨论卫星随时间的运动。该内核将直接用于后续星下点模型和星座覆盖优化。

## 2. 符号与几何关系

设：

| 符号 | 含义 | 单位 |
|---|---|---|
| \(R\) | 地球平均半径 | km |
| \(h\) | 卫星轨道高度 | km |
| \(r=R+h\) | 卫星轨道半径 | km |
| \(O\) | 地心 | — |
| \(S\) | 卫星位置 | — |
| \(P\) | 波束边缘与地表的交点 | — |
| \(\alpha=\angle OSP\) | 天线半锥角，即波束边缘相对星下方向的离轴角 | rad 或 ° |
| \(\psi=\angle SOP\) | 覆盖边界地心角 | rad |
| \(\ell=|SP|\) | 卫星到覆盖边界点的斜距 | km |
| \(e\) | 覆盖边界点看卫星的仰角 | rad 或 ° |

天线波束轴指向地心，覆盖边缘由射线 \(SP\) 与球面相交得到。由于波束绕星下方向轴对称，覆盖区在球面上是以星下点为中心的球冠；在局部地图投影中可近似为圆，远离局部等距投影时会出现投影变形。

## 3. 覆盖边界地心角推导

### 3.1 射线与球面的可交条件

在三角形 \(OSP\) 中，\(|OS|=r\)、\(|OP|=R\)。由正弦定理，覆盖边缘存在地表交点的条件为

\[
r\sin\alpha\le R.
\]

因此天线半锥角必须满足

\[
0\le\alpha\le\alpha_{\rm hor}
=\arcsin\left(\frac{R}{r}\right),
\]

其中 \(\alpha_{\rm hor}\) 为指向地球切线时的最大离轴角。若波束角更大，多出的波束不会落到地球表面，实际覆盖边界由地平线截断。

### 3.2 地心角解析式

由正弦定理，三角形在地面点 \(P\) 处的内角满足

\[
\sin\angle OPS=\frac{r}{R}\sin\alpha.
\]

对于朝向地球的近端交点，\(\angle OPS\) 为钝角，故

\[
\angle OPS=\pi-arcsin\left(\frac{r}{R}\sin\alpha\right).
\]

再由三角形内角和

\[
\alpha+\psi+\angle OPS=\pi,
\]

得到

\[
\boxed{
\psi=\arcsin\left(\frac{R+h}{R}\sin\alpha\right)-\alpha
}.
\]

该式适用于 \(0\le\alpha\le\alpha_{\rm hor}\)。当波束覆盖至地平线时，最大地心角为

\[
\boxed{
\psi_{\rm hor}=\arccos\left(\frac{R}{R+h}\right)
}.
\]

### 3.3 等价的斜距表达

沿波束边缘求射线与地球球面的近端交点，可得斜距

\[
\boxed{
\ell=r\cos\alpha-
\sqrt{R^2-r^2\sin^2\alpha}
}.
\]

再由余弦定理可写为

\[
\psi=arccos\left(\frac{r^2+R^2-\ell^2}{2rR}\right).
\]

该表达适合在程序实现时进行交叉校验：两种公式所得 \(\psi\) 应在数值误差范围内一致。

## 4. 地面覆盖半径与面积

### 4.1 球面弧长口径

以星下点到覆盖边界的最短大圆弧长作为地面覆盖半径，则

\[
\boxed{s=R\psi}.
\]

这一口径最适合覆盖优化，因为两个地面点之间同样使用大圆距离判定。

### 4.2 覆盖面积

球面上极角不超过 \(\psi\) 的区域为球冠，其面积为

\[
A=\int_0^{2\pi}\int_0^\psi R^2\sin\theta\,\mathrm d\theta\,\mathrm d\lambda,
\]

因此

\[
\boxed{A=2\pi R^2(1-\cos\psi)}.
\]

当 \(\psi\ll1\) 时，\(1-\cos\psi\approx\psi^2/2\)，于是

\[
A\approx\pi(R\psi)^2=\pi s^2,
\]

即局部平面圆面积是球冠面积的小角度近似。

## 5. 最低仰角与覆盖角的等价表示

若工程上改用最低仰角 \(e_{\min}\) 定义可见性，则三角形内角关系给出

\[
\alpha+\psi+e_{\min}=\frac{\pi}{2}.
\]

消去 \(\alpha\) 后可得常用形式

\[
\boxed{
\psi=\arccos\left(\frac{R}{R+h}\cos e_{\min}\right)-e_{\min}
}.
\]

这说明“天线半锥角”和“最低仰角”不能混用。题面给定的是天线半锥角，因此主模型使用前述 \(\alpha\) 公式；仰角形式只用于解释和敏感性分析。

## 6. 任意地面点覆盖判据

设卫星星下点经纬度为 \((\varphi_s,\lambda_s)\)，待检验地面点经纬度为 \((\varphi,lambda)\)。两者的球面角距离 \(d\) 满足

\[
\cos d=sin\varphi\sin\varphi_s+
\cos\varphi\cos\varphi_s\cos(\lambda-\lambda_s).
\]

为减小反余弦在 \(d\approx0\) 附近的数值误差，覆盖判断可直接写为

\[
\boxed{
\sin\varphi\sin\varphi_s+
\cos\varphi\cos\varphi_s\cos(\lambda-\lambda_s)
\ge \cos\psi
}.
\]

满足该不等式时记覆盖指示量 \(I=1\)，否则 \(I=0\)。多星覆盖重数为各卫星覆盖指示量之和。

## 7. 题面参数计算与一致性校核

取题面参数

\[
R=6371\ {\rm km},\qquad h=550\ {\rm km},\qquad
\alpha=40.46^\circ.
\]

由解析式计算得到：

| 指标 | 计算结果 |
|---|---:|
| 轨道半径 \(r\) | 6921 km |
| 覆盖边界地心角 \(\psi\) | 4.3645° |
| 地面覆盖弧长 \(s\) | 485.31 km |
| 球冠覆盖面积 \(A\) | 739,559 km² |
| 边界斜距 \(\ell\) | 747.15 km |
| 边界对应仰角 \(e\) | 45.18° |
| 地平线地心角 \(\psi_{\rm hor}\) | 22.9961° |

题面称该半锥角“对应地面覆盖半径约 506 km”。严格球面模型给出的 485.31 km 比标称值小 20.69 km，相对差约 4.09%。反向计算表明，若严格球面弧长恰为 506 km，则所需半锥角约为 41.56°。

可能原因包括：

1. 题面使用了不同的地球半径、轨道高度或近似几何；
2. 506 km 是工程标称值而非由 40.46°精确推导的数值；
3. “覆盖半径”使用了不同的投影或距离口径。

## 8. 后续统一口径

为兼顾数学严谨性和题面意图，后续采用双口径处理：

- **主模型**：使用 \(R=6371\) km、\(h=550\) km、\(\alpha=40.46^\circ\) 的严格球面几何，覆盖半径取 485.31 km；
- **稳健性情景**：使用题面标称覆盖半径 506 km，等价地取 \(\psi=506/R\)，检验最优星座规模是否改变。

若两种口径得到相同的最优整数配置，则结论稳健；若最优配置发生变化，则以严格几何结果为主，并把题面标称口径结果作为对照方案报告。

## 9. 模型检验

### 9.1 极限检验

- 当 \(\alpha\to0\) 时，\(\psi\to0\)、\(s\to0\)、\(A\to0\)，符合窄波束极限；
- 当 \(h\to0\) 时，\(r\to R\)，有 \(\psi\to0\)，卫星贴近地表时波束覆盖范围趋于零；
- 当 \(\alpha\to\alpha_{\rm hor}\) 时，\(\psi\to\psi_{\rm hor}\)，覆盖边界恰落在地平线。

### 9.2 单调性检验

在波束尚未达到地平线的范围内，提高轨道高度或增大天线半锥角都会增大 \(\psi\)、\(s\) 和 \(A\)，与物理直觉一致。

### 9.3 设计评审

**结论：通过。**

解析模型给出了唯一明确的角度定义、覆盖判据和实现公式，并通过等价公式、极限行为及题面标称值完成校核。遗留的不确定性仅是题面 506 km 的口径差异，已通过双口径敏感性方案控制。

## 10. 下一步接口

下一步建立圆轨道卫星位置与星下点随时间变化模型，输出 \((\varphi_s(t),\lambda_s(t))\)。将其代入第 6 节覆盖判据，即可计算任意地点、任意时刻的覆盖状态。
