# 问题二：多轨道面覆盖评价与最小规模优化模型

## 1. 建模目标

在轨道高度固定为 550 km、轨道面升交点均匀分布的条件下，确定：

\[
(M,N,i,\Omega_0,F,u_0),
\]

其中 \(M\) 为轨道面数、\(N\) 为每轨卫星数、\(i\) 为轨道倾角、\(\Omega_0\) 为首个轨道面的升交点赤经、\(F\) 为 Walker 相位因子、\(u_0\) 为初始公共相位。目标是在满足目标区域连续覆盖约束的前提下，使总卫星数

\[
S=MN
\]

最少，并比较单重覆盖与二重覆盖场景的规模和成本差异。

## 2. 目标区域及球面离散

目标区域定义为

\[
\mathcal R={(\varphi,\lambda):
4^\circ\le\varphi\le53^\circ,
73^\circ\le\lambda\le135^\circ\}.
\]

采用经纬度网格离散区域。由于相同经度间隔在不同纬度对应的实际面积不同，不能直接对网格点做等权平均。网格点 \(g\) 的面积权重取

\[
\boxed{w_g=\cos\varphi_g},
\]

归一化后满足

\[
\widetilde w_g=\frac{w_g}{\sum_{q\in\mathcal G}w_q},
\qquad
\sum_{g\in\mathcal G}\widetilde w_g=1.
\]

目标区域的球面面积为

\[
\boxed{
A_{\mathcal R}=R^2(\lambda_2-\lambda_1)
(\sin\varphi_2-\sin\varphi_1)
},
\]

角度均使用弧度。代入题面范围得到

\[
A_{\mathcal R}\approx3.2014\times10^7\ {\rm km^2}.
\]

该面积是经纬度矩形的球面面积，包括区域边界内的海域；与题面给出的矩形服务范围一致。

## 3. 星座参数化

### 3.1 轨道面布局

升交点在赤道上均匀分布：

\[
\boxed{
\Omega_m=\Omega_0+\frac{2\pi m}{M},
\quad m=0,1,\ldots,M-1
}.
\]

### 3.2 卫星相位

第 \(m\) 个轨道面、第 \(k\) 颗卫星的纬度幅角为

\[
\boxed{
u_{m,k}(t)=u_0+nt+rac{2\pi k}{N}
+\frac{2\pi Fm}{MN}
},
\]

其中

\[
k=0,1,\ldots,N-1,
\qquad F\in\{0,1,\ldots,M-1\}.
\]

由上一节的 ECI–ECEF 模型得到每颗卫星星下点 \((\varphi_{s,mk}(t),\lambda_{s,mk}(t))\)，再由球面角距离判定覆盖。

## 4. 覆盖状态及核心评价指标

令

\[
C_g(t)=\sum_{m=0}^{M-1}\sum_{k=0}^{N-1}I_{m,k,g}(t)
\]

表示时刻 \(t\) 网格点 \(g\) 的覆盖重数。

### 4.1 瞬时区域覆盖率

\[
\boxed{
R_1(t)=\sum_{g\in\mathcal G}
\widetilde w_g\,\mathbf 1[C_g(t)\ge1]
}.
\]

它表示时刻 \(t\) 被至少一颗卫星覆盖的区域面积比例。

### 4.2 时空综合覆盖率

\[
\boxed{
\overline R_1=
\frac{1}{|\mathcal T|}
\sum_{t\in\mathcal T}R_1(t)
}.
\]

该指标适合比较总体表现，但不能单独证明连续覆盖，因为少量短时空缺会被平均值掩盖。

### 4.3 每点时间覆盖率

\[
\boxed{
A_{1,g}=\frac{1}{|\mathcal T|}
\sum_{t\in\mathcal T}\mathbf 1[C_g(t)\ge1]
}.
\]

区域最差点可用度为

\[
\boxed{A_{1,\min}=\min_{g\in\mathcal G}A_{1,g}}.
\]

### 4.4 平均覆盖重数

\[
\boxed{
\overline C=rac{1}{|\mathcal T|}
\sum_{t\in\mathcal T}
\sum_{g\in\mathcal G}\widetilde w_g C_g(t)
}.
\]

它反映冗余水平，但较高的平均覆盖重数仍可能与局部空洞并存。

### 4.5 最小覆盖重数

\[
\boxed{
C_{\min}=\min_{t\in\mathcal T}
\min_{g\in\mathcal G}C_g(t)
}.
\]

单重严格连续覆盖要求 \(C_{\min}\ge1\)。

### 4.6 最大覆盖间隙

对每个网格点，将 \(C_g(t)=0\) 的连续时间段长度记为 \(L_{g,r}\)，则

\[
\boxed{
G_{\max}=\max_g\max_r L_{g,r}
}.
\]

满足严格连续覆盖时应有 \(G_{\max}=0\)。对未满足约束的候选方案，该指标能比平均覆盖率更清楚地揭示最严重的服务中断。

### 4.7 二重覆盖指标

定义每点二重覆盖时间比例

\[
\boxed{
A_{2,g}=\frac{1}{|\mathcal T|}
\sum_{t\in\mathcal T}\mathbf 1[C_g(t)\ge2]
},
\]

以及最差点二重覆盖可用度

\[
\boxed{A_{2,\min}=\min_g A_{2,g}}.
\]

## 5. 题面二重覆盖要求的口径

题面同时出现“95%以上的时间实现二重覆盖”和“任意时刻区域内任一点至少被两颗卫星可见”。前者是 95% 时间可用度，后者是 100% 严格二重覆盖，两者并不等价。

主模型采用与“95%以上时间”一致、且对每个位置都公平的约束：

\[
\boxed{A_{2,\min}\ge0.95}.
\]

同时额外报告：

\[
\overline R_2=\frac{1}{|\mathcal T|}
\sum_t\sum_g\widetilde w_g\mathbf 1[C_g(t)\ge2]
\]

和严格二重覆盖指标 \(C_{\min}\ge2\) 是否成立。这样既回答题面 95% 要求，也不回避括号中更强的解释。

## 6. 优化模型

### 6.1 单重覆盖模型

采用词典序优化：首先最小化总卫星数，其次最大化覆盖裕度，再最小化成本。

\[
\boxed{
\min_{M,N,i,\Omega_0,F,u_0} S=MN
}
\]

约束为

\[
\begin{aligned}
&C_g(t)\ge1,
&&\forall g\in\mathcal G,\ \forall t\in\mathcal T,\\
&M,N\in\mathbb Z_+,\\
&40^\circ\le i\le60^\circ,\\
&F\in\{0,1,\ldots,M-1\},\\
&0\le\Omega_0,u_0<2\pi.
\end{aligned}
\]

在相同 \(S\) 下，定义最小角度裕量

\[
\boxed{
\rho_{\min}=min_{g,t}
\left[\psi-\min_{m,k}d_{m,k,g}(t)\right]
}
\]

并优先选择 \(\rho_{\min}\) 更大的方案。

### 6.2 二重覆盖模型

\[
\boxed{
\min S_2=MN
}
\]

约束替换为

\[
\boxed{A_{2,g}\ge0.95,\qquad\forall g\in\mathcal G}.
\]

相同卫星数下，优先最大化 \(A_{2,\min}\)，再最小化最大二重覆盖间隙。

## 7. 解析下界与搜索域缩减

### 7.1 倾角必要条件

要覆盖区域北边界 \(53^\circ\mathrm N\)，星下点最高纬度 \(i\) 加覆盖地心角 \(\psi\) 至少达到 53°：

\[
i+\psi\ge53^\circ.
\]

严格球面口径 \(\psi=4.3645^\circ\) 下，得到

\[
\boxed{i\ge48.6355^\circ}.
\]

因此无需搜索 40°–48.6355°的倾角。

### 7.2 面积下界

单星球冠覆盖面积约为

\[
A_s=7.3956\times10^5\ {\rm km^2}.
\]

即使假设所有卫星覆盖区都完全落在目标区域且互不重叠，单重覆盖仍至少需要

\[
\boxed{
S\ge\left\lceil\frac{A_{\mathcal R}}{A_s}\right\rceil=44
}.
\]

二重覆盖的理想面积下界为

\[
\boxed{
S_2\ge\left\lceil\frac{2A_{\mathcal R}}{A_s}\right\rceil=87
}.
\]

由于实际卫星覆盖区大量落在区域外并存在重叠，真实最优规模必然高于这两个下界。它们主要用于排除不可能的总卫星数，而不是预测最终答案。

### 7.3 因子分解搜索

从 \(S=44\) 开始按总卫星数递增，对每个 \(S\) 枚举所有满足 \(S=MN\) 的正整数因子对。找到首个通过严格认证的 \(S\) 后，才停止向更大规模搜索。这样可以在给定参数化和搜索精度下支持“最少”结论。

## 8. 成本模型

题面给出单星制造成本 500 万元，一箭 60 星、单次发射成本 2 亿元。对总卫星数 \(S\)，初始部署成本为

\[
\boxed{
C_{\rm deploy}(S)
=5\times10^6S
+2\times10^8\left\lceil\frac{S}{60}\right\rceil
}.
\]

定义发射次数

\[
L(S)=\left\lceil\frac{S}{60}\right\rceil.
\]

单重和二重方案成本差为

\[
\boxed{
\Delta C=C_{\rm deploy}(S_2)-C_{\rm deploy}(S_1)
}.
\]

由于发射成本呈阶梯变化，总卫星数略微增加并不总导致成本平滑变化；跨越 60 的整数倍时会额外增加一次 2 亿元发射费用。

## 9. 求解策略

不直接使用遗传算法，而采用“解析剪枝—确定性枚举—局部精化—保守认证”四层方法。

### 9.1 第一层：解析剪枝

- 总卫星数从单重 44、二重 87 起搜索；
- 倾角限定为 48.6355°–60°；
- 排除明显无法在经向形成连续覆盖的过小 \(M\)；
- 利用相邻轨道面间距和单轨相位间距进一步给出保守筛选。

### 9.2 第二层：粗粒度确定性枚举

建议初筛参数为：

| 参数 | 初筛步长/范围 |
|---|---|
| 倾角 \(i\) | 0.5° |
| \(F\) | 全部合法整数 |
| \(\Omega_0\) | 利用均匀布局对称性，只搜索一个轨道面间隔 |
| \(u_0\) | 利用同轨均匀性，只搜索一个卫星相位间隔 |
| 空间网格 | 1°×1° |
| 时间步长 | 60 s |
| 仿真时域 | 1 个恒星日 |

### 9.3 第三层：候选方案局部精化

对粗筛最优及其邻域使用：

- 倾角步长 0.1°；
- \(\Omega_0\)、\(u_0\) 小步长坐标搜索；
- 0.25°或更细空间网格；
- 5–10 s 时间步长；
- 至少 1 个恒星日，并补充 3 日稳定性检查。

### 9.4 第四层：保守覆盖认证

单纯检查离散网格中心可能漏掉单元内部或相邻时刻之间的覆盖空洞。对空间网格最大半对角角距记为 \(\varepsilon_s\)，时间步内卫星相对地面最大角位移上界记为

\[
\varepsilon_t\approx(n+\omega_e)\frac{\Delta t}{2}.
\]

定义收缩后的认证覆盖角

\[
\boxed{
\psi_{\rm cert}=\psi-\varepsilon_s-\varepsilon_t
}.
\]

若所有网格中心、所有采样时刻在 \(\psi_{\rm cert}\) 下仍满足覆盖约束，则原始覆盖角 \(\psi\) 对相应时空单元具有保守覆盖保证。若 \(\psi_{\rm cert}\le0\)，必须继续细化网格和时间步长。

这一认证机制把“网格上看起来 100%”提升为具有明确误差余量的连续覆盖结论。

## 11. 模型局限性

1. 规则化 Walker 参数化可能排除某些非均匀区域星座；若规则方案与面积下界差距过大，将放开升交点和相位做局部非均匀优化；
2. 矩形经纬度区域包含实际服务区之外的部分海域，使结果偏保守；
3. 二体轨道无法描述长期节点漂移，最终候选需增加 \(J_2\) 情景复核；
4. “100%覆盖”只能相对于明确的时空范围和误差认证尺度陈述，不能把有限采样直接宣称为数学上的永久覆盖。

## 12. 设计评审

**结论：通过。**

模型完整定义了问题二的变量、目标、约束、评价指标、成本和求解顺序。面积下界与纬度下界提供解析剪枝，保守覆盖角提供离散仿真的误差控制。下一阶段可以据此实现确定性搜索，而无需临时补充模型口径。
