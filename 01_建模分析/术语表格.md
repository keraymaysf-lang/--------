# 低轨卫星星座建模术语与符号表

## 一、核心概念术语

| 中文名称 | 英文名称 | 缩写 | 定义 |
|---|---|---|---|
| 低地球轨道 | Low Earth Orbit | LEO | 通常位于约 200–2000 km 高度的地球轨道 |
| 星座 | Satellite Constellation | — | 按统一任务设计运行的多颗卫星系统 |
| 轨道面 | Orbital Plane | — | 由卫星轨道确定并通过地心的平面 |
| 星下点 | Sub-satellite Point | SSP | 卫星与地心连线在地表的交点 |
| 覆盖区 | Coverage Footprint | — | 单颗卫星在某时刻可服务的地表区域 |
| 升交点赤经 | Right Ascension of Ascending Node | RAAN | 升交点相对惯性参考方向的角位置 |
| 纬度幅角 | Argument of Latitude | — | 卫星从升交点沿轨道量取的角位置 |
| Walker 星座 | Walker Constellation | — | 轨道面和相位按规则均匀配置的星座 |
| 星间链路 | Inter-Satellite Link | ISL | 卫星之间的直接通信链路 |
| 地心惯性坐标系 | Earth-Centered Inertial | ECI | 不随地球自转的地心参考系 |
| 地心地固坐标系 | Earth-Centered Earth-Fixed | ECEF | 随地球自转的地心参考系 |
| 连续覆盖 | Continuous Coverage | — | 指定区域在规定时域内不存在覆盖中断 |
| 覆盖重数 | Coverage Multiplicity | — | 同时覆盖某地面点的卫星数量 |
| 覆盖间隙 | Coverage Gap | — | 地面点连续不被覆盖的时间段 |
| 覆盖可用度 | Coverage Availability | — | 系统满足基本覆盖条件的时间比例 |
| 星座鲁棒性 | Constellation Robustness | — | 卫星退出或环境扰动下维持服务的能力 |
| 在轨备用星 | On-orbit Spare | — | 已部署在轨、用于故障接替的冗余卫星 |
| 地面备用星 | Ground Spare | — | 存放地面、待后续发射补网的卫星 |

## 六、成本与单位约定

| 符号 | 含义 | 单位 |
|---|---|---:|
| \(C_{\rm deploy}\) | 初始部署成本 | 元 |
| \(C_m\) | 规避机动成本 | 元 |
| \(C_{\rm repl}\) | 替换发射成本 | 元 |
| \(C^{5\rm yr}\) | 五年总成本 | 元 |
| \(T_L\) | 设计寿命 | 年 |

统一约定：几何计算内部角度全部使用弧度；距离统一使用 km，涉及引力参数时必须与距离单位一致；传播时延统一使用 ms；通信容量统一使用 Gbps；成本内部使用人民币元，表格可换算为万元或亿元。

## 七、待情景化参数

| 参数 | 原因 | 处理方式 |
|---|---|---|
| \(B_{\rm ISL}\) | 题面未给 ISL 容量 | 多档容量扫描 |
| \(D_0\) | 题面未给平均总业务量 | 需求缩放与临界吞吐量 |
| \(L_p\) | 题面未给平均分组长度 | 排队时延敏感性分析 |
| \(r_s,n(d),f_v(v)\) | 碰撞环境信息不足 | 低/中/高风险情景 |
| \(P_{th},\tau_m,p_m\) | 规避策略未给 | 阈值和持续时间扫描 |
| \(\lambda_{\rm other}\) | 非碰撞故障率未给 | 可靠性情景参数 |
